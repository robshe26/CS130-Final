# Data Sets Overview 

## Cars CSV File 
 _https://corgis-edu.github.io/corgis/csv/cars/_

- This file contains a dataset that specifies cars and the amount of fuel that they use.

#### Questions 

- What is the average city miles per gallon of every car that is on the list
   - 17.28 miles per gallon
- Does the type of car (ex.Truck, Sedan, SUV, etc.) have an effect on the gas mileage?

## Labor CSV File 
_https://corgis-edu.github.io/corgis/csv/labor/_

- This file contains a dataset that provides information on the labor force, employment, unemployment, persons not in the labor force, hours of work, earning, and other demographic and labor force characteristics.

#### Questions 

- Does the time of year have an effect on unemployment rates?
- Do demographics have an effect on the employment rates or earnings?
